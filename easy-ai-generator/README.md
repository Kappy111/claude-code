# Free Image + Video Generator (works from a Chromebook)

1. Upload `Free_Image_Video_Generator.ipynb` to https://colab.research.google.com (File → Upload notebook).
2. Runtime → Change runtime type → **T4 GPU** → Save.
3. Press the ▶️ play button. Wait ~10 minutes.
4. Open the link printed at the bottom.
5. In the app: Workflow → Browse Templates → **SDXL** for images, **LTX-Video** for video.

Free Colab allows a few GPU hours per day. Re-run the notebook tomorrow to get the same setup back.
