VidToText — Chrome extension (Load unpacked)

HOW TO INSTALL ON A CHROMEBOOK / CHROME:
1. Unzip this folder (if it's still a .zip): in the Files app, right-click the
   zip and choose "Extract all". You'll get a folder named "extension".
2. Open Chrome and go to:  chrome://extensions
3. Turn ON "Developer mode" (toggle in the top-right).
4. Click "Load unpacked".
5. Select this "extension" folder (the one containing manifest.json).
6. A "V" VidToText icon appears in your Chrome toolbar. Click it to open the app.

If "Developer mode" or "Load unpacked" is greyed out, your Chromebook is
managed by a school/organization that blocks extensions. In that case use the
app directly at https://kappy111.github.io/claude-code/ , or in Chrome click
the ⋮ menu -> Cast, save & share -> Create shortcut -> check "Open as window"
to get an app icon without an extension.
